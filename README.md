# E-commerce Sales and Customer Behavior Analysis

## Project Overview
This project analyzes the Online Retail II dataset to understand sales performance, customer purchasing patterns, product trends, and customer segmentation.

## Objectives
- Analyze overall sales and revenue.
- Identify top-performing products and countries.
- Understand monthly and hourly sales trends.
- Analyze repeat customer behavior.
- Perform RFM analysis to segment customers.
- Generate business insights and recommendations.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- MySQL
- Power BI
- Jupyter Notebook

## Key Findings
- Highest revenue month: November 2011 (£1,452,115.98).
- Top-performing product: REGENCY CAKESTAND 3 TIER (£330,590.32).
- Highest revenue country: United Kingdom (£16,802,775.56).
- Repeat customers: 72.35%.
- Largest customer segment: Hibernating (1,511 customers).
- Highest revenue customer segment: Champions (£11,598,734.29).
- Return value ratio: 3.65%.

## Project Structure
- `notebooks/` – Data cleaning, analysis, and visualizations.
- `data/` – Dataset and processed data.
- `visualizations/` – Generated charts.
- `sql/` – SQL queries.
- `dashboard/` – Power BI dashboard.

## How to Run
1. Clone or download this repository.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Place the dataset in the `data/raw/` folder.
4. Open the Jupyter Notebook and run the cells.

## Conclusion
This project demonstrates how Python, SQL, and Power BI can be used to analyze retail data, identify customer behavior patterns, and generate actionable business insights.
